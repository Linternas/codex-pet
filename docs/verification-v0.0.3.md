# v0.0.3 검증

- 타입 검사, 린트, 빌드 통과. 테스트 19개 파일 / 75개 통과.
- 키보드 프로세스 ready / permission-required / 종료 상태에 따라 true / false / null 전환 테스트.
- 설치 번들 복사본에서 isPackaged=true와 버전0.0.3 확인.
- 설정 창 blur→숨김, 캐릭터 렌더러 클릭과 app.focus 강제 활성화 후에도 숨김 유지, 상태바 재진입, 창 닫기 후 클릭으로 생성되지 않음 확인.
- 설치 확인 취소, 권한 경고 해제, 설정 화면 크기 슬라이더 제거 확인. 오버레이 드래그·크기 조절 구현 유지.
- 실제 CGEvent 마우스 주입은 테스트 환경에서 전달되지 않아 물리 마우스 경로를 직접 검증했다고 주장하지 않음. 컴퓨터 조작 도구도 Orca 런타임 비실행으로 사용 불가. 대신 설치 번들에서 macOS 앱 활성화 경로를 직접 호출하여 검증.
- v0.0.2의 Electron 실행 파일명으로 인한 개발 실행 판정을 수정: CFBundleExecutable과 바이너리 이름을 Codex Pet으로 통일.
- v0.0.2→v0.0.3은 수동 설치 필요. Sparkle feed/ZIP은 이번 릴리스에 함께 게시해야 함.
