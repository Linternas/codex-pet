## 캐릭터 제어

- 메뉴바에서 자동 산책을 시작하거나 멈추고, 캐릭터를 숨기거나 다시 표시할 수 있습니다.
- 클릭 통과를 켜면 캐릭터 뒤에 있는 앱을 클릭할 수 있습니다.
- 마지막으로 직접 배치한 위치와 크기를 앱을 다시 열 때 복원합니다.

## 작업 세션

- 작업 세션 화면에서 로컬 Codex와 Claude Code를 연결할 수 있습니다.
- 프로젝트명, 세션 ID, 최근 요청의 앞부분과 상태가 표시됩니다. 캐릭터도 작업, 입력·승인 대기, 응답 완료에 맞춰 움직입니다.
- Codex는 새 세션의 `/hooks`에서 추가된 훅을 신뢰해야 합니다.

## 업데이트 안내

- 업데이트 후 키보드 반응에 필요한 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다.
