수정
• 설정 창이 포커스를 잃으면 숨겨 캐릭터 클릭으로 다시 앞으로 나오지 않도록 수정했습니다. 설정 창은 상단 상태바에서만 다시 엽니다.
• 실제 키보드 감지 프로세스의 권한 상태를 기준으로 헤더 알림을 표시합니다. 키보드 반응이 가능한데도 권한 경고가 나타나는 문제를 수정했습니다.
• 권한 허용·해제를 주기적으로 확인해 알림을 갱신합니다.

• 설치본을 개발 실행으로 잘못 판정해 업데이트 기능이 비활성화되는 패키징 문제를 수정했습니다.

화면 정리
• 설정 화면의 캐릭터 크기 조절 슬라이더를 제거했습니다. 크기는 데스크톱 캐릭터의 우하단 핸들을 드래그해 조절할 수 있습니다.

업데이트 안내
• v0.0.2 설치본은 업데이트 인식 오류가 있어 v0.0.3 DMG를 수동 설치해 주세요. 이후 버전부터 앱 내 업데이트를 사용할 수 있습니다.
