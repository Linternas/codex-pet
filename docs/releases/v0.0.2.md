캐릭터
• pet ID로 캐릭터를 다운로드하고 적용·삭제할 수 있습니다.
• 삭제한 캐릭터가 앱 재실행 시 복원되지 않도록 수정했습니다.
• v1·v2 시트 차이와 v2의 16방향 시선을 지원합니다.
• 빈 프레임을 건너뛰어 애니메이션을 재생합니다.
• 키보드 입력 시작 시 인사하고, 입력 지속·중단에 따라 작업·검토·휴식·대기로 전환합니다.
• 클릭은 인사, 더블클릭은 점프, 드래그는 달리기로 반응합니다. 동작 버튼에서 9개 애니메이션을 선택할 수 있습니다.
• 크기 조절에 Lucide 아이콘을 적용했습니다.

설치 및 권한
• npx가 없으면 헤더에 설치 버튼을 표시합니다.
• 설치 내용과 위치를 확인하고 동의하면 Node.js와 npx를 자동 설치합니다. 별도 PKG 실행 없이 설치 후 캐릭터 다운로드가 활성화됩니다.
• 기존 Node.js와 시스템 설정은 변경하지 않고 앱 전용 사용자 폴더를 사용합니다.
• 손쉬운 사용 권한이 없으면 헤더의 권한 설정에 붉은 테두리와 알림을 표시합니다. 권한 허용 후 다시 확인해 알림을 해제합니다.
• 캐릭터 영역에서 설치·권한 안내를 제거해 목록 공간을 넓혔습니다.

앱 및 업데이트
• Dock에 표시하지 않고 상단 상태바로 실행합니다. 설정 창은 상태바에서만 열립니다.
• 배경을 제거한 강아지 PNG를 앱과 상태바 아이콘에 적용했습니다.
• codex-pets.net 링크를 헤더에 배치하고 기본 웹 브라우저로 엽니다.
• 앱 내 버전 히스토리에서 현재 패치 노트와 GitHub 릴리스를 확인할 수 있습니다.
• Sparkle 업데이트를 추가했습니다. 새 버전이 있으면 헤더에 아이콘이 표시되고, 다운로드 후 재시작하여 설치할 수 있습니다.
• 업데이트 ZIP과 목록에 서명을 적용하고, 검증에 실패한 업데이트를 차단합니다.
• 다운로드 버튼의 배경과 테두리를 제거했습니다.

수정
• 패키징한 앱의 캐릭터 이미지 로딩과 권한 설정 버튼 동작을 수정했습니다.
• 다운로드 오류가 다른 상태 메시지로 덮이는 문제를 수정했습니다.

배포 안내
• 이전 버전에는 자동 업데이트 기능이 없으므로 v0.0.2는 수동 설치해야 합니다.
• macOS 최초 실행 보안 허용과 손쉬운 사용 권한은 필요할 수 있습니다.
