## 자동 산책과 멀티 모니터

- 캐릭터가 같은 모니터의 여러 높이와 구역을 돌아다닙니다. 쉬는 동안 가끔 인사하거나 점프합니다.
- 아래쪽 모니터에서 위쪽 모니터로 캐릭터를 끌 때 메뉴바 경계에 걸리던 문제를 수정했습니다.

## 설정 화면

- 캐릭터 미리보기와 동작 메뉴를 정리하고 반복 설명을 줄였습니다.
- Codex와 Claude Code마다 현재 연결 상태와 연결 버튼 하나를 표시합니다.
- 권한 설정과 버전 히스토리의 문구를 간결하게 정리했습니다.

## 업데이트 안내

- 업데이트 후 키보드 반응에 필요한 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다.
